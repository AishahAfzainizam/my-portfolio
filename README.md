# My Portfolio (Next.js + Tailwind CSS)

## Run it
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Customize
- Name, text: `components/Hero.tsx`, `components/About.tsx`
- Projects: `data/projects.ts`
- Email and social links: `components/Contact.tsx`, `components/Footer.tsx`
- Colors: `tailwind.config.ts`; fonts: `app/layout.tsx`

## Deploy
Push to GitHub and import the repo on vercel.com.
